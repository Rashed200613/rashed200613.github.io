## Course Overview

This course gives a fundamental idea about the common theoretical phenomena in computer programming techniques. It also provides a bridge to students' previous concepts about basic computer knowledge.

**Course Code:** CSE 0611-1101 | **Credit:** 3.00 | **Total Marks:** 100

## Course Objectives

- Familiarize students with the history of computers
- Help them know the laws of computing with different number systems
- Make them understand the computer system and its workflow
- Make students able to understand the fundamental techniques of programming
- Acquire preliminary ideas of structured programming using a specific programming language
- Enable students to develop and debug basic C programs using problem-solving skills

## Course Learning Outcomes (CLOs)

After successful completion of the course, students will be able to:

- **CLO1.** Demonstrate a solid understanding of computer fundamentals, including hardware, software, operating systems, and computer networks and security basics
- **CLO2.** Develop and debug basic C programs, demonstrating proficiency in program design and code implementation
- **CLO3.** Design and implement algorithms to solve computational problems, using C programming constructs such as loops, conditionals and functions
- **CLO4.** Analyze and solve simple programming problems using the C programming language, applying fundamental programming concepts such as variables, data types, control structures, functions and arrays
- **CLO5.** Apply basic debugging and testing techniques to identify and resolve errors in C programs, ensuring program correctness and reliability
- **CLO6.** Work collaboratively in teams to solve programming problems, effectively communicating their solutions and incorporating feedback
- **CLO7.** Analyze the social implications of computing technologies, recognizing ethical considerations, privacy concerns and the impact of technology on society
