## Course Overview

The aim of the course is to provide students with knowledge and skills of developing, testing and debugging real-life and society-targeted web applications. The course describes the fundamental types of web technologies and how they can be used to provide real business benefit, explores new technologies and issues affecting web development, and covers the process of developing information systems, the concepts of web engineering and web process reengineering, and the skills needed by web development professionals.

**Course Code:** CSE 0613-3233 | **Credit:** 3.00 | **Total Marks:** 100

## Course Objectives

- Familiarize students with the principles and functioning of web architectures on modern devices
- Enable students to design real-life and society-targeted client-server based web applications
- Teach students to use web tools and technologies to develop real-life and society-targeted client-server based web applications

## Course Learning Outcomes (CLOs)

After successful completion of the course, students will be able to:

- **CLO1.** Analyze and understand the principles and concepts of desktop and web software development, including client-server architecture, user interface design and the software development life cycle
- **CLO2.** Design and develop desktop and web applications using appropriate programming languages, frameworks and tools, demonstrating proficiency in software development techniques and practices
- **CLO3.** Create user-friendly and intuitive user interfaces for desktop and web applications, applying principles of user experience (UX) design and considering accessibility requirements
- **CLO4.** Implement database functionality in desktop and web applications, including data modeling, querying and management, ensuring data integrity and security
- **CLO5.** Apply software testing techniques to ensure the functionality, reliability and quality of desktop and web applications, including unit testing, integration testing and user acceptance testing
- **CLO6.** Collaborate effectively in software development teams, demonstrating strong communication, teamwork and project management skills
- **CLO7.** Identify and address ethical and legal considerations in desktop and web software development, including privacy, security, intellectual property and accessibility
- **CLO8.** Adapt to emerging technologies and advancements in desktop and web software development, demonstrating a commitment to lifelong learning and professional development
